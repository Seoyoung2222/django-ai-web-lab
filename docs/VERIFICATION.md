# 검증 기록

검증일: 2026-11-18. macOS, Python 3.12.4, 별도 임시 가상환경에서 루트 `requirements.txt`를 설치했습니다. 기존 사용자 DB와 원본 ZIP은 수정하지 않았습니다.

## 통과한 항목

- Python 소스 64개 AST 문법 파싱
- 번호 생성, 투표, 얼굴/눈 검출 프로젝트의 Django system check
- 세 프로젝트 각각 임시 SQLite DB에 migration 적용
- 번호 생성: 목록/입력/상세 HTTP 200, 정상 생성 POST redirect, 기본 5묶음/각 6개/1~45 범위/묶음 내 중복 없음/오름차순 점검
- 원본 번호 생성 테스트 1개 통과
- 투표: 빈 목록, 질문 상세, 선택지 누락 처리, 정상 투표와 득표 수 증가, 결과 화면, 없는 질문 404 점검
- 얼굴 검출: 첫 화면/두 업로드 화면 HTTP 200, 두 Cascade XML 로딩, 800×600 합성 흰색 PNG 업로드 및 640×480 출력 저장 점검
- 감성 추론 함수: tokenizer/model 대역을 사용한 `(1, 128)` 입력 배열과 긍정/부정 결과 매핑 점검
- GitHub 토큰, AWS access key, private key, 고정 Django key 및 일부 비밀 할당 패턴 검색에서 일치 없음

## 수행하지 않은 항목

- 실제 인물 사진에 대한 얼굴/눈 검출 정확도, 처리 속도 측정
- 웹 브라우저의 시각적 배치, 모바일 화면, 접근성 점검
- KoBERT 모델 다운로드, TensorFlow 환경 구축, H5 가중치 로딩, 실제 추론 및 정확도 측정
- 운영 배포, 보안 침투 테스트, 동시성/부하 테스트

감성 분석 관련 대역 테스트는 웹 앱 전체 실행이나 모델 품질 검증이 아닙니다. AST 파싱에서 `inference_bert.py`의 일반 문자열 정규식 `\\s`에 Python SyntaxWarning이 발생했지만 문법 파싱은 통과했습니다. 원본 표현을 유지했습니다.

## 코드 보존 범위

기능 코드는 원본에서 복사하고 설정의 비밀키/호스트 처리와 감성 분석 import 누락만 정리했습니다. 원본 가상환경, DB, 업로드 사진, 모델 가중치, 리뷰 데이터는 커밋 대상에서 제외했습니다. 제외된 실행 자료가 있는 감성 분석은 추가 준비 없이 바로 실행할 수 있다고 주장하지 않습니다.
